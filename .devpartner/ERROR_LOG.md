## ERR-010 — 2026-10-07 — Full test suite flaked under parallel load on the shared machine

| Field          | Content                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Context**    | Full `pnpm test` after Unit 1e-iii added `TerrainScene.test.tsx` (10 files, 135 tests). The same tests passed in isolation and in pairwise runs.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Symptom**    | Three tests failed only in the full run: SceneGate's error-boundary test (`Unable to find role="fallback"` — RTL's 1000ms `findByRole` wait), TerrainScene's loading test and heightfield's 32-bit test (`Test timed out in 5000ms`). Durations ballooned: heightfield 11.9s, SceneGate 8.2s, TerrainScene 7.7s — all at once.                                                                                                                                                                                                                                     |
| **Root cause** | Contention, not code. Vitest runs files in parallel by default; the box has 4 cores carrying three background `opencode` processes and system services with ~2.2GB RAM free, so 10 simultaneous jsdom environments plus 479k-vertex geometry builds produced multi-second CPU/GC stalls that ate both RTL's 1s wait and Vitest's 5s default. Raising `testTimeout` alone would not have fixed the RTL wait — only removing the contention does. A gate that is red under the machine's real load is a broken gate (ADR-009), regardless of being green when quiet. |
| **Resolution** | `vitest.config.ts`: `fileParallelism: false` (deterministic; also mirrors CI's 2-core runners, which would hit the same pileup at 10 files) and `testTimeout: 10_000` for the genuinely heavy geometry tests, both with a rationale comment. Full suite then green: 135/10 in 107s.                                                                                                                                                                                                                                                                                |
| **Prevention** | When tests fail only in the full run, reproduce with subset/pairwise runs to separate contention from real interaction bugs before touching code. Prefer a slow deterministic gate over a fast flaky one; assert on the machine's actual load profile (shared, background-tooling-heavy), not an ideal idle one.                                                                                                                                                                                                                                                   |
| **Related**    | ADR-009 (gate discipline), S-EVOL-010                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

| **Context**    | CI red on `main` after `944e26d`/`d45ca22` added `msw@2.15.0` (run 37495712891, all four jobs) — while the identical `pnpm install --frozen-lockfile` exited 0 locally.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

## ERR-001 — 2026-10-05 — Source flood dataset is vector extents, not depth rasters

| Field          | Content                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Context**    | Pre-flight data verification before Unit 1. PROJECT_STATE assumed a raster "depth grid → water surface" pipeline based on the dataset title and the depth-threshold values quoted in search metadata.                                                                                                                                                                                                                                                                                                             |
| **Symptom**    | Catalog record reports `Spatial representation type: Vector`, `Format: GeoPackage`. There is no raster depth product.                                                                                                                                                                                                                                                                                                                                                                                             |
| **Root cause** | The metadata sentence "Maximum depths were converted into extents using various thresholds" means the _thresholds were applied before publishing_ — each published layer is a binary footprint (inside ≥0.1m, ≥0.2m, or ≥0.3m), not a continuous depth value. Our earlier reading treated the thresholds as if depth rasters were published separately.                                                                                                                                                           |
| **Resolution** | Pipeline is extent-based, not depth-value-based. For each rainfall scenario × threshold we hold one polygon set. Per-cell depth is **not** available and must not be implied. Storage is GeoPackage (WGS 84), which we parse at build time into our own compact binary rather than shipping the GeoPackage to the browser. Design impact: the water surface renders as stacked threshold layers, and a numeric depth readout shows a _class_ (">0.3m"), never a false point value. Requires an ADR — see ADR-003. |
| **Prevention** | Any dataset claim is verified against the publisher's own catalog record (format, spatial representation type, CRS), never against a third-party summary or search snippet.                                                                                                                                                                                                                                                                                                                                       |
| **Related**    | ADR-003, RISK-007                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

## ERR-006 — 2026-10-05 — `pnpm typecheck` compiled zero files and always passed

| Field            | Content                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Context**      | Unit 1c-iii — DEM fetch script. A call site in `demResample.test.ts` was missing an argument after a refactor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Symptom**      | `pnpm typecheck` exited 0. `pnpm test` then failed with a type error surfaced by Vitest's transform rather than by tsc. The gate reported green and the next gate caught it — but only by luck.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Root cause**   | `typecheck` ran `tsc --noEmit` against the **root** `tsconfig.json`, which is solution-style: it holds only `references` and has no `files` or `include`. `tsc --listFiles` on that config printed **zero** files. `tsc --noEmit` type-checked nothing and exited 0, which is indistinguishable from success. Every prior "typecheck passing" claim in this project — including in the CI workflow and in my own reporting — was therefore meaningless. The real program lives in `tsconfig.app.json` (263 files, tests included) and is only reached by `tsc -b`, which the `build` script happened to use: `build` was checking types while `typecheck` was not. |
| **Resolution**   | `typecheck` is now `tsc -p tsconfig.app.json --noEmit && tsc -p tsconfig.node.json --noEmit`. Explicit per-project invocation is preferred over `tsc -b` because `-b` trusts its `.tsbuildinfo` cache, and a pre-commit gate should do the full check rather than depend on a cache being valid.                                                                                                                                                                                                                                                                                                                                                                   |
| **Verification** | Proved with a canary rather than assumed. Appending `const c: string = computeDemGrid(300, 200).cols` gives: old gate exit **0** with no output; `tsc -p tsconfig.app.json --noEmit` exit **2** with `TS2322`. Removing the canary returns exit 0. Exit codes were read without piping, since `$?` after a pipe into `head` reports head's status.                                                                                                                                                                                                                                                                                                                 |
| **Prevention**   | A gate must be shown to fail. When a CI or commit check is added or changed, break something on purpose and confirm the check catches it before trusting a green run. Separately: a solution-style root tsconfig makes the obvious command (`tsc --noEmit`) silently useless, so scripts should use explicit `-p`.                                                                                                                                                                                                                                                                                                                                                 |
| **Related**      | ERR-003. Same species — a gate that cannot fail. That one inflated 61 tests to 1,498 by collecting dependency suites; this one reported a pass over 0 type-checked files.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## ERR-004 — 2026-10-05 — Mean-radius sphere put Kampala's north-south extent 125m out

| Field          | Content                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Context**    | Unit 1c-ii — adding `metresPerDegreeLatitude`/`metresPerDegreeLongitude` so the DEM fetch script can reproject WGS84 into the metre space the terrain mesh uses (ADR-005).                                                                                                                                                                                                                                                  |
| **Symptom**    | Not a crash. `src/lib/geo.ts` multiplied every degree span by a single `EARTH_RADIUS_M = 6_371_008.8`, so `boundsHeightMeters()` reported 22,461.41m for the published extent where WGS84 gives 22,336.01m. The existing tests passed, because they only asserted loose bounds (`> 18_000`, `< 28_000`) and that height exceeded width.                                                                                     |
| **Root cause** | A sphere is a reasonable stand-in at continental scale and a bad one at city scale. The two axes are wrong by opposite amounts — +125m north-south, −21m east-west — because a real ellipsoid's meridian radius and parallel radius diverge with latitude while a sphere's radius does not. The error grows as the extent does, and nothing in the code flagged it.                                                         |
| **Resolution** | Replaced the sphere with WGS84 (`a = 6_378_137`, `1/f = 298.257223563`): meridian metres-per-degree from M(φ) = a(1−e²)/(1−e²sin²φ)^1.5, parallel metres-per-degree from N(φ)cos(φ) = a·cos(φ)/√(1−e²sin²φ). Extent is now 19,258.00m × 22,336.01m. Tightened the bounds tests to ~500m-wide ranges plus exact-value regression pins so the sphere model cannot return. Requires an ADR — see ADR-007.                      |
| **Prevention** | Assert tight tolerances on geospatial maths, not order-of-magnitude ones. A test that only proves "bigger than X" and "smaller than Y" will pass through a systematic error of many percent. Pin exact expected values so a modelling change has to be deliberate. Also: a heightfield fixture that hardcodes grid dimensions derived from a projection encodes that projection silently — derive them in the test instead. |
| **Related**    | ADR-005, ADR-006, ADR-007                                                                                                                                                                                                                                                                                                                                                                                                   |
